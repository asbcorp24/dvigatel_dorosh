# Управление двигателем — ПЛК200 / INNOVERT

Проект управления трёхфазным асинхронным двигателем через ОВЕН ПЛК200-04-CS и INNOVERT IMD222U21E-ENC.

**Архитектура:** ПК — Ethernet/Modbus TCP — ПЛК200 — RS-485/Modbus RTU — частотник — двигатель. Трёхпроводный Pt100 подключается к аналоговому входу ПЛК; энкодер подключён к частотнику.

**Команда ПК:** целевая скорость (об/мин), время плавного перехода (с), направление. При реверсе сначала торможение до подтверждённого нуля, затем разгон в обратную сторону. Остановка — команда с нулевой скоростью.

**ВНИМАНИЕ:** Репозиторий содержит проектные материалы, не готовую к запуску промышленную систему. Управление силовым оборудованием запрещено до проверки электрической схемы, конфигурации и механизмов безопасности на стенде. Modbus-команды не заменяют аппаратный безопасный останов.

Разработка ведётся в отдельных ветках и PR.
