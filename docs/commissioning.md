# Пусконаладка: движение заблокировано до проверок

1. Зафиксировать фактические схемы электрических соединений, 220 В Δ на двигателе, PE, номинал защиты, допустимые нагрузки и назначение аппаратного останова.
2. Проверить Pt100 без вращения: измерение, обрыв, короткое замыкание, диагностика канала ПЛК.
3. Проверить связь ПЛК200↔INNOVERT чтением по Modbus RTU **без записи команд движения**.
4. Сверить регистры выходной скорости, тока, статуса, аварии и качество связи; подтвердить состояние энкодера на ПЧ и число импульсов/оборот.
5. Считать/архивировать текущие параметры ПЧ, ввести паспортные данные мотора 220 В Δ / 8,8 А / 2,2 кВт / 50 Гц / 1420 об/мин, затем настраивать PG только по официальной инструкции.
6. Поднять Modbus TCP на ПЛК и проверить карту команд и телеметрии без разрешения движения. Heartbeat должен вызывать останов/блокировку по проектному алгоритму, если компьютер перестал отвечать.
7. Испытать аварийный останов независимо от Ethernet и RS-485; проверить реакцию при потере связи, аварии ПЧ, отказе PG и Pt100.
8. На безопасном механическом стенде и под надзором персонала испытать низкую скорость, плавный останов, реверс только после доказанной остановки, ограничения ускорения/тока, защиту от перезапуска.
9. Зафиксировать в протоколе измеренные задержки, допуски, версию ПЧ, прошивку ПЛК и фактические масштабные коэффициенты регистров.

**Статус по умолчанию:** `CommissionEnable = FALSE`, `ConfigValid = FALSE`. Не изменять до закрытия соответствующих пунктов.
