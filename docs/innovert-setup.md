# Настройка частотника INNOVERT IMD222U21E-ENC для ПЛК200

**Статус: инструкция по предварительной настройке и пусконаладке.** Значения сверены по руководству серии IMD_E и фотографиям шильдиков пользователя (2026-11-10). Совместимость версии прошивки исполнения **-ENC** со всеми приведёнными функциями, энкодером и картой Modbus должна быть подтверждена до запуска.

Руководство: https://rospolus.ru/doc/chastotniki/INNOVERT/IMD-E/innovert-imd-e-manual.pdf
Страница серии изготовителя: https://innovert.ru/innovert-imd_e/

## 0. Перед изменениями

1. Отключить команду движения ПЛК; зафиксировать аппаратную безопасную цепь, убедиться, что механизм и рабочая зона безопасны.
2. Считать и записать ВСЕ текущие значения изменяемых параметров, а также идентификатор версии ПО ПЧ. Не выполнять «сброс на заводские», не делать настройки вслепую.
3. Проверить схему подключения двигателя в клеммной коробке: **220 В треугольник Δ**, 8,8 А. Преобразователь выдаёт **0–220 В трёхфазного напряжения**, а не 380 В.
4. Убедиться, что реальное торможение возможно за требуемое время, с учётом инерции. Резистор торможения — по документации привода и расчёту нагрузки, не по догадке.
5. Проверить питание и электрический интерфейс энкодера, целостность экрана и правильность подключения именно к плате PG частотника. Монтаж выполнять только при полностью снятом питании.

## 1. Паспортные данные двигателя — вводим первыми

| Параметр | Значение для двигателя | Примечание |
|---|---:|---|
| **P63.00** | **2,2 кВт** | Номинальная мощность |
| **P63.01** | **220 В** | Только для соединения **Δ** |
| **P63.02** | **8,8 А** | Для 220 В Δ, НЕ 5,1 А |
| **P63.03** | **50,00 Гц** | Номинальная частота |
| **P63.04** | **1420 об/мин** | Паспортные обороты, не 1500 |
| **P63.05** | **4** | **Число полюсов**, НЕ пар полюсов |
| **P63.06** | **0** | Асинхронный двигатель |
| P63.07 | сначала **0** | Автонастройка отключена до отдельной процедуры; 1 — статическая, 2 — динамическая |
| P63.08 | сначала оставить исходный безопасный режим; **2** после проверки PG | 2 = векторное управление с обратной связью (PG); НЕ включать до проверки направления, PPR и параметров двигателя |

**Важно:** в ST-блоке `FB_DriveCommand` используется **MotorPolePairs=2**, это ПАРЫ полюсов для расчёта частоты; параметр ПЧ **P63.05=4**, это ПОЛЮСА. Нельзя записывать в P63.05 значение 2.

### Автонастройка
После ввода паспортных характеристик выполнить штатную процедуру идентификации двигателя по руководству именно этой версии ПЧ. Динамическая автонастройка может вращать вал; допускается только после оценки механической нагрузки, отключения опасных связей и контроля зоны. Без этого этапа не считать настройку закрытого векторного управления завершённой.

## 2. Энкодер: сначала проверяем, затем включаем замкнутый контур

| Параметр | Предлагаемое значение / действие |
|---|---|
| **P61.00** | **0** только если подтверждён обычный инкрементальный A/B без Hall UVW |
| **P61.01** | **1024** *после подтверждения маркировки энкодера / его паспорта* |
| **P61.03** | **0 или 1**, в зависимости от фактической последовательности A/B при «вперёд» |
| **P61.04** | **1000** при прямой механической связи, после проверки |
| **P61.05** | **1000** при прямой механической связи, после проверки |
| P61.11–P61.15 | Пороги защиты по превышению/ошибке скорости и потере энкодера — подбираются при пусконаладке; не отключать защиту для обхода ошибок |

**Не перепутать:** «1024» в маркировке двигателя похоже на PPR энкодера, но нужно сверить модель датчика. Отсутствует документальное подтверждение типа линии (TTL, HTL, RS-422) и электрической совместимости платы PG.

**До перехода на P63.08=2:**
- Проверить аппаратную плату PG, питание и фазировку по руководству.
- Без вращения проверить диагностику/отсутствие ошибок платы.
- На безопасном стенде проверить достоверность скорости и направление. ПЧ должен показывать 0 об/мин на полностью остановленном валу и изменение соответствующего знака/направления при контролируемом вращении.
- Проверить, что `U00.07 / 0x8107` действительно отображает **измеренную скорость PG** при вашей конфигурации; в мануале это «выходная скорость», источник не гарантирован.
- Только затем включить векторное управление с PG по полной процедуре изготовителя.

## 3. Источник управления и частота — после чтения телеметрии

| Параметр | Рекомендуемое значение / действие |
|---|---|
| **P01.00** | **2** — команды от интерфейса связи; переключать только после готовности PLC/аппаратной защиты |
| **P01.01** | Для источника «связь» разряд **сотен = 0** (использовать цифровую уставку P00.00). Другие разряды сохранять согласно фактической конфигурации; **не устанавливать целиком «000» без необходимости** |
| **P00.01** | **0** — основное цифровое задание |
| **P00.06** | Разряд единиц **0** — основная уставка частоты |
| **P01.03** | **0** — разрешить реверс, только при доказанной логике блокировки реверса ПЛК |
| **P01.04** | Выдержку смены направления согласовать с требованиями механики (ПЧ дополняет запрет ПЛК) |
| **P01.10** | **0** — штатный останов с замедлением, а не выбег |
| **P00.07** | **50,00 Гц** — первичное консервативное ограничение для паспортной частоты 50 Гц |
| **P00.08** | **50,00 Гц** — верхняя граница; менять лишь после расчёта механической безопасности |
| **P00.09** | **0,00 Гц** — нижняя граница, чтобы можно было задать останов |
| **P02.00 / P02.01** | Время ускорения/замедления подбирать по нагрузке; заводские рампы ПЧ должны согласовываться с рампой ПЛК, иначе заданное время ПК не гарантируется |

**Принцип управления:** ПК отправляет `SetMotor(speedRPM, rampSeconds, direction)`; ПЛК строит профиль с плавным снижением скорости до нуля, ждёт подтверждения остановки, затем меняет направление. ПЧ отвечает за собственные ограничения тока, момента и рамп. При быстрой смене задания необходимо проверить, что входные рампы ПЧ не искажают динамику сверх разрешённого времени. Не пытайтесь «компенсировать» задержку снятием защит.

## 4. Настройки RS-485 Modbus RTU

| Параметр | Значение |
|---|---|
| **P50.00** | **1** — адрес ведомого устройства |
| **P50.01** | **31** — клеммный RS-485 = 38400 бит/с; порт панели = 9600 бит/с |
| **P50.02** | **00** — RTU 8N1 на обоих портах |
| **P50.03** | Первоначально 0,000 с; корректировать лишь при проблемах обмена |
| **P50.04** | Тайм-аут связи **должен быть активен и проверен**. Значение 0,0 означает, что обнаружение тайм-аута отключено. Конкретный порог установить после измерения периодов и проверки поведения ПЧ; одного тайм-аута недостаточно для гарантированного безопасного останова |
| **P50.05** | Оставить по умолчанию до проверки назначения маски ответов и диагностики |
| P50.09 | Не переключать на другие платы/протоколы без необходимости; используем встроенный последовательный RS-485 |

Сначала проверка только FC03 **чтение**, потом поэтапное добавление FC06 **записи** после наладки.

ПЛК: 38400, 8 бит данных, без чётности, 1 стоп-бит, ведомый адрес 1. При разных версиях интерфейса клеммы обозначены по-разному — сверить маркировку физической платы ПЧ. Двухпроводная дифференциальная шина, экранирование и согласование по инженерной схеме.

## 5. Список Modbus для проверки на стенде

| Регистр PDU (hex) | Операция | Назначение |
|---|---|---|
| `0x8100` | FC03 | Рабочая частота |
| `0x8102` | FC03 | Выходная частота |
| `0x8107` | FC03 | Выходная скорость об/мин; **не равна автоматически PG-обратной связи** |
| `0x810A` | FC03 | Ток |
| `0x8118` | FC03 | Статус |
| `0x812B` | FC03 | Код ошибки |
| `0x0000` | FC03/FC06 | P00.00: цифровое задание частоты, 0,01 Гц в единице согласно примеру руководства |
| `0x8000` | FC06 | Командное слово: бит 0 пуск, бит 1 обратное направление, бит 2 останов с замедлением |

**Внимание:** запись в `0x8000` с битом пуска приводит к реальному движению. На начальном этапе её не выполнять. Не выполнять циклическую перезапись EEPROM: выяснить механизм сохранения уставок в этой версии ПЧ.

## 6. Рекомендованный порядок через панель ПЧ

1. В состоянии STOP сохранить текущие P63, P61, P01, P00, P02 и P50.
2. Записать P63.00–P63.06 из таблицы двигателя (после проверки Δ).
3. Проверить P61.00–P61.05 и совместимость платы энкодера; НЕ включать PG без проверки.
4. Настроить и испытать защитные параметры и безопасный останов.
5. Настроить P50.00–P50.04 и получить устойчивое **чтение** ПЧ по Modbus RTU.
6. Проверить реальную скорость/направление, затем провести идентификацию двигателя по официальной процедуре и установить P63.08=2 только при подтверждённой PG-обратной связи.
7. Лишь после полного завершения программного и аппаратного проекта переключить P01.00=2, проверив источник P00.00 и возможность независимого аппаратного останова.
8. Испытать на безопасной механике разгон, торможение, реверс, обрыв RS-485, потерю Ethernet, отказ Pt100, неисправность энкодера и ПЧ.

## 7. Что пока не подтверждено

- Разрешение и интерфейс реального энкодера.
- Реакция ПЧ на P50.04: тайм-аут обнаружения связи не означает гарантированную остановку.
- Точный адрес и семантика PG-измеренного направления для исполнения -ENC.
- Назначение всех клемм на вашей аппаратной ревизии и доступность аппаратной функции STO.
- Время, которое механическая система выдержит при торможении без перенапряжения DC-шины.
- Фактическая компиляция проекта CODESYS и обмен на оборудовании.

**Движение заблокировано до завершения этих проверок.**
