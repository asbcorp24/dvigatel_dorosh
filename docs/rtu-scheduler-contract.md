# Modbus RTU: контракт планировщика (ещё не реализован)

**Почему не включены прямые записи:** CODESYS ОВЕН/драйверы Modbus отличаются по именам FB, полям запросов и статусу, поэтому без package/конкретной версии нельзя корректно и проверяемо создать `Modbus Serial Master` как ST код. Подключать запись `0x8000` к неотлаженному проекту опасно.

## Автомат обмена
- `INIT`: прочитать версию/идентификатор ПЧ, параметры связи.
- `READ_SPEED`: FC03 0x8107, один регистр; сохранить значение и timestamp успешного ответа.
- `READ_STATUS`: FC03 0x8118, один регистр; сохранить значение и timestamp.
- `READ_FREQ`: FC03 0x8102.
- `READ_CURRENT`: FC03 0x810A.
- `READ_FAULT`: FC03 0x812B.
- `WRITE_SETPOINT`: только после всех защит и валидной команды, FC06 0x0000; проверить адрес/код функции/значение ответа.
- `WRITE_CONTROL`: только после успеха частотной записи и подтверждения допустимого направления, FC06 0x8000.
- `BACKOFF`: при ошибке отключить программное разрешение движения, считать данные недостоверными, диагностировать причину.

По каждой операции: одно активное Modbus-задание, ограниченный тайм-аут, фиксированный предел повторов, контроль переключения состояния request busy/done/error, статистика ошибок.

## Взаимодействие с ПЛК
- После чтения скорости/статуса формируйте соответствующие флаги `SpeedResponsePulse` / `StatusResponsePulse` на один цикл.
- В текущем `PRG_MotorMain` упрощённый `DriveReadFresh` означает успешное обновление комплекта. **До реализации планировщика оставлять FALSE**.
- `DriveSpeedSignedRPM`: измеренный/проверенный канал скорости; `DriveStatusDecoded` и `DriveReportsStopped` — результаты подтверждённой расшифровки.
- Успешная **запись** команд обязательна для контроля исполнения; текущий код лишь формирует `PendingFrequencyWord/PendingControlWord`.
- При зависании/потере RS-485 частотник может продолжить вращение. Обязательны настроенная функция потери связи ПЧ и независимая аппаратная цепь безопасного останова.

### Разделение задач
Невозможно гарантировать конкретные точные 5 с физического разгона при произвольной нагрузке, поскольку ПЧ ограничивает момент, ток, торможение. Время — уставка профиля ПЛК; фактическое достижение контролировать по энкодеру.

### Защитный запрет
Пока scheduler/декодирование/сброс аварии не готовы: `CommissionEnable = FALSE`, `ConfigValid = FALSE`. Не обходите эти флаги установкой TRUE для демонстрации.
